# D05 帕累托图

本次只关闭 D05 的帕累托切片；旭日、Icicle、留存与贡献/流量平衡仍待实现。
文档及交互示例：`/#/components/pareto`。开发分支 `feat/d05-pareto` 承接 B17 分支。

## 数据口径

`packages/common/src/logic/pareto.ts` 的 `buildPareto` 是唯一统计入口。
输入为稳定 ID、类别名及数值；降序排列，相同数值保持输入次序，不修改输入。
输出包含原始行号、有效值合计、分类占比、累计值、相对柱高、阈值首次到达名次及排除明细。
所有适配器接收同一个可序列化 `ParetoModel`；Flutter 接收对应 JSON Map，不再移植统计函数。

- 缺失、负值与非有限数不进入分母，分别列明排除原因；零值保留。
- 阈值须在 `(0, 1]`；重复或空 ID、非法阈值及合计溢出返回无效模型。
- 全零时累计无定义，不画伪造的累计曲线；空数据不遗留旧行。
- 数值默认保留最多六位小数，小于百万分之一的非零值使用科学计数，避免显示成零。
- 80% 是默认观察阈值，不作“二八规律”承诺。累计只说明数量构成，不说明因果。

## 渲染与消费

Vue3 / Vue2 / React 使用 SVG，图外标签使用实际 CSS 字号；不会随 viewBox 缩小。
小程序使用 Canvas，颜色从共享语义样式读取；Flutter 使用主题语义颜色和 CustomPainter。
累计点独立绘制，只有一个类别时也能看见 100% 数据点。数据清单始终提供文本读法和选择入口。
受控 `selectedId` 使用稳定 ID；Vue 的 `select`、React/Flutter 的 `onSelect` 返回 ID，
小程序的 `select` 事件使用 `detail.id`。默认高度 220px，可用 `height` 调整。

Vue3 的入口清单此前为手写，本次新增 `build:vue-index`，按目录生成导出和全量注册，
由 `build:vue-next` 调用；命令与类型导出保持原声明。
组件清单、矩阵、属性、注册表、Vue2 转换、React/Flutter 导出及小程序附属文件均通过 `build:*` 生成。
覆盖矩阵从 152 增至 153 个各端齐备组件，无覆盖回退。

小程序与 Flutter 本轮仅通过仓库静态检查；没有 SDK/真机运行证据，不标记 runtime-verified。
Web 包已通过 `build:packages` 编译与入口检查；专项交互实测为 Vue3 文档站。
