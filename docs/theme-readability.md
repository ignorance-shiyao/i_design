# 主题配置与暗色可读性调整

配置入口：顶栏调色板。支持预设/自定义主题色、按下/常态/悬停/衬底预览、圆角和字号档位、明暗切换方式、组件动效、恢复默认与浏览器本地保存。面板可通过关闭按钮或 Escape 关闭，Escape 关闭后焦点回到入口。

修正明暗切换后的色阶预览缓存、暗色自定义品牌色过暗、存储中的非法参数和禁止存储时的异常。圆角与字号以公共令牌为基准；首页文字同步响应字号配置。关闭动效时覆盖 CSS 固定时长过渡，主题切换直接生效。系统减少动效设置继续优先。

暗色公共令牌提高辅助文字、注释、代码标点与输入边界对比度；暗色品牌色保留色相并提升最低明度。通过令牌生成器同步 Web、移动和 Flutter 产物。首页暗色图像压低亮度干扰，主按钮使用实际 on-brand 前景色。

验证：
- `npm run build`（含 Vue/TypeScript 检查）。
- `node scripts/check-theme-readability.mjs`：检查默认暗色正文/次级/辅助文字与四类基础表面，最低 5.75:1；代码配色、品牌预设、边界、持久化、恢复、缩放、动效和色阶响应。
- 浏览器截图与实际点击验收仍待完成，当前浏览器不能访问本地预览。数值检查使用令牌与模拟 DOM，不等同于整站 WCAG 合规认证。

对比度提示按 [WCAG 2.2 SC 1.4.3](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) 区分普通文字 4.5:1 与大字 3:1。普通按钮文字不能因为位于控件上而按 3:1 判定。自定义品牌色未必满足普通文字门槛，面板保留实际数值提示。
