# 主题配置与暗色可读性调整

配置入口：顶栏调色板。面板按令牌类别分页——色彩、字体、圆角、阴影、尺寸、动效、导出：

- **色彩**：预设与自定义主题色、按下/常态/悬停/衬底色阶预览与对比度提示；成功/警告/错误三类语义色各自可选可自定义，衬底由基色推导；中性色偏移把主题色的色相掺进灰阶，只改彩度不改明度。
- **字体**：字体族（系统/衬线/等宽）、字号档位与逐级自定义（每一级给出令牌名、用途与当前像素值）、正文行高。
- **圆角**：档位与 sm/md/lg/xl 逐级自定义。直角与圆全不随档位变化。
- **阴影**：无/轻/默认/重与自定义强度系数；强度同时作用于透明度与模糊半径，暗色另有一套基准值。
- **尺寸**：密度档位、间距倍率、控件高度逐级自定义，并列出缩放后的完整间距刻度。
- **动效**：组件动效开关、动效速度、明暗切换方式。
- **导出**：把当前配置解算出的令牌覆盖导出为亮暗两套 CSS，可复制。

「选择 → 令牌」的换算在 `packages/common/src/logic/theme.ts`，与框架无关，各端共用同一份；站点的 `useThemeConfig` 只负责响应式、写 DOM 与本地存储。面板可通过关闭按钮或 Escape 关闭，Escape 关闭后焦点回到入口。

修正明暗切换后的色阶预览缓存、暗色自定义品牌色过暗、存储中的非法参数和禁止存储时的异常。圆角与字号以公共令牌为基准；首页文字同步响应字号配置。关闭动效时覆盖 CSS 固定时长过渡，主题切换直接生效。系统减少动效设置继续优先。

暗色公共令牌提高辅助文字、注释、代码标点与输入边界对比度；暗色品牌色保留色相并提升最低明度。通过令牌生成器同步 Web、移动和 Flutter 产物。首页暗色图像压低亮度干扰，主按钮使用实际 on-brand 前景色。

验证：
- `npm run build`（含 Vue/TypeScript 检查）。
- `node scripts/check-theme-readability.mjs`：检查默认暗色正文/次级/辅助文字与四类基础表面，最低 5.75:1；代码配色、品牌预设、边界、持久化、恢复、缩放、动效和色阶响应。
- Playwright 实机截图：面板七个分页、字号自定义档、切换主题色后的全站效果、极端配置（衬线字体 + 自定义圆角 + 130% 间距 + 175% 阴影 + 60% 中性色偏移）下的亮暗两态，控制台无报错。
- `node scripts/check-scoped-css.mjs`：`<style scoped>` 编译出的规则必须带 data-v 属性。暗色下曾因 `:global([data-theme="dark"]) .hero-art` 被编译成 `[data-theme=dark]{opacity:.16}`，整个 `<html>` 变成 16% 不透明度，全站文字与卡片一起发灰——构建与数值检查都不会报错，故补此检查。
- 数值检查使用令牌与模拟 DOM，不等同于整站 WCAG 合规认证。

对比度提示按 [WCAG 2.2 SC 1.4.3](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) 区分普通文字 4.5:1 与大字 3:1。普通按钮文字不能因为位于控件上而按 3:1 判定。自定义品牌色未必满足普通文字门槛，面板保留实际数值提示。
