# D05 层级汇总：旭日与 Icicle

本次关闭 D05 的层级切片：共享的汇总契约，以及旭日、Icicle 两张图的各端渲染。
留存与贡献/流量平衡仍待实现。示例页：`/#/components/sunburst`、`/#/components/icicle`。

## 数据口径

`packages/common/src/logic/hierarchy.ts` 的 `buildHierarchy` 是唯一入口。
输入是扁平的父子行（稳定 ID、父 ID、名称、数值），输出一棵可直接渲染的树。
两张图消费同一个 `HierarchyModel`，Flutter 接收对应 JSON Map，不移植汇总算法。

三条定死的口径：

- **父子对不上时不替读者挑一个。** 父级自报 100、下级只报 80，差额 20 单列成
  「未细分」子节点，有自己的扇段/格子、名称、占比与清单条目。取父级的数会让那 20
  从图上消失，取下级之和会让合计不再是业务方认的数——两种都是在替读者做决定，
  而读者看不出你做过。反过来下级之和**超过**父级是矛盾不是缺口，补不出来，
  整个模型判无效并指名节点。浮点零头（相对父级 1e-9 以下）不补，否则每个父级下面
  都会挂一个宽度为零、却能被读屏器念出来的空节点。
- **分母说得出是谁。** 每个节点同时给 `share`（占根合计）与 `shareOfParent`
  （占直接父级），文字读法两个都念。一段占 12%，占全体还是占上级，差着一整层的语义。
- **排除项留在清单里。** 缺失、负值、非有限数不进分母；被排除的节点连同整条下级
  一起排除并逐个记原因，且与输入行序无关。**叶子的 null 是缺失，不是零**——
  没有下级可汇总却记成 0，图上会多出一块占比 0.0% 的节点，读者会当成「确实是零」。
  有下级的节点不给值是另一回事，那是由下级汇总而来，合法且常见。

无效状态还包括：空 ID、重复 ID、与「未细分」保留后缀冲突的 ID、指向不存在的父级、
父子成环（含挂在正常树旁边、永远走不到根的那一支）、合计溢出。

`hierarchyView(model, focusId)` 负责下钻：把焦点那一支重新摊满整条轴，
否则下钻三层之后那一支只剩百分之几的宽度，点都点不中。**占比仍按原来的分母报**——
焦点变了不等于数据变了。`hierarchyPath` 给面包屑那条路。

## 取色

取色号（`colorIndex`）按**支**发：同一个顶层祖先下的所有层共用一个号。
逐层换色会让读者以为层与层之间有对应关系。号算在模型里而不是渲染时算——
下钻后视图里只剩一支，在视图上重新编号会让同一支在下钻前后变成两种颜色。

第九支起不再循环取色（`CHART_PALETTE_SIZE` = 8）：绕回第一个色，读者会把第九支和
第一支当成同一类，比没有颜色更糟。超出的支与「未细分」都用中性色，身份由清单里的
文字承担。颜色从来不是唯一线索。

## 几何

- **旭日**（`logic/sunburst.ts`）：把 0–1 摊成同心圆环。起点扳到十二点
  （SVG 的 0 弧度在正右方），整圈拆成两个半弧——起止点重合时「走哪条弧」未定义，
  浏览器画成一个点，于是单根数据、下钻到某一支之后整张图是空的。
  环宽按**实际要画的层数**均分，下钻之后剩几层就撑满几层。
- **Icicle**（`logic/icicle.ts`）：摊成一排横向矩形，每行一层。
  同时给像素与百分比两组坐标：Web 端用 HTML 盒子按百分比排宽度、行高用固定像素；
  Canvas 与 CustomPainter 用像素那组。窄到写不下名字的格子由 `labelFits` 标出来，
  按字数估算（估窄一点，宁可少写），渲染层据此只画色块。

两张图在同一份数据上的 id 顺序与取色号逐项相等，有专门的用例盯着。

## 渲染与消费

Vue3 / Vue2 / React：旭日用 SVG path，Icicle 用 HTML 盒子。
**Icicle 不用 SVG 是量出来的结论**：viewBox 是整体缩放，实测 320px 下整张图只剩
31px 高，行高与字跟着宽度缩到三分之一，低于 9px 的可读下限。换成盒子后三档宽度下
高度都是 84px（三层 × 28）。

Icicle 格子里的标签压在实心色块上，字色跟着底色成对取（`--i-chart-N-ink`），
不是一律白字——八个分类色里有四个上的白字连 3:1 都到不了。
实测亮暗两态八个标签对比度 4.56–4.71:1。小程序 Canvas 不写格内标签：
在 Canvas 上挑字色要自己算，名字交给清单更稳。

受控 `focusId` / `selectedId` 用稳定 ID；Vue 的 `select` / `focus`、
React / Flutter 的 `onSelect` / `onFocus` 返回 ID，`focus` 返回空串表示返回全部。
小程序事件的 ID 在 `detail.id`。Flutter 额外接收 `sunburstSectors` /
`icicleCells` + `icicleHeight` 的结果。

小程序与 Flutter 本轮仅通过仓库静态检查；没有 SDK/真机运行证据，不标 runtime-verified。
