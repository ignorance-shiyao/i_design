# B16 账号与权限页面模式

入口：文档站「账号与权限」，`/#/design/access`。

## 可操作范围

- 模拟登录、退出与停用账号拒绝；不采集密码，不接入真实身份服务。
- 个人名称与通知偏好修改；取消时确认未保存的输入，失败时保留表单。
- 用户角色、所属组织与启用状态调整；固定角色的权限说明。
- 扁平组织新建、名称变更；用户关联以组织 ID 保留，不随改名断开。
- 角色同时影响菜单、字段和动作；主管的用户投影没有邮箱属性，成员只有个人设置。

页面由已有的 Button、Input、Select、Checkbox、FormPage、Tag 组合，
这些基础组件的各端适配未修改。本次没有新增公共组件，也不把文档页组合标成原生端运行验证。
组织树、自定义角色、账号邀请与删除、真实认证和跨组织隔离不在本次范围。

## 共享模型与边界

`packages/common/src/logic/access-pattern.ts` 是该配方唯一的角色矩阵与事务实现。
模型保存用户、组织以及逐对象递增的 revision。会话只引用用户 ID，不复制一份角色，
因此角色变化或停用后，旧会话会按最新快照得到收敛后的权限。

读取目录先做字段投影；写操作重新取当前身份、重新授权、校验目标版本。
个人设置只接受名称和通知偏好，不允许通过附加字段改 ID 或角色。
至少保留一名启用的管理员；组织名不能为空或重复；无效组织引用被拒绝。
所有写操作返回下一份快照，校验失败不修改原值。

401 要求重新登录；403 表示缺少权限；404 表示目标不存在；
409 要求重新打开最新对象；422 保留输入并指出字段或业务约束。
界面内使用明确标注的同步内存模型，刷新重置，不能用这些前端判定替代服务端鉴权。

主管字段和动作限制、成员菜单、个人设置保存、最后管理员保护与取消编辑确认。
