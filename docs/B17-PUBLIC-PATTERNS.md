# B17 公共网页模式

入口：文档站「公共网页」，`/#/design/public`。

## 已实现范围

- 概览：Hero、功能卡片与真实组件文档入口。
- 示例方案：按月和按年切换；年付醒目金额是全年总额，另列参考月均。
- FAQ：鼠标、Enter 和空格可展开与收起。
- 帮助：搜索标题、摘要、分类和正文；空格分隔关键词时同时匹配。
- 文章直达、空结果清空、失效文章与未知栏目恢复入口。
- 更新日志：示例记录可进入相关帮助文章。

栏目、计价周期、已提交搜索词和文章位置来自 URL，支持刷新、分享和浏览器前进后退。
打开文章再返回列表会保留搜索条件；栏目切换会移除无关参数。
导航更新后将焦点移到内容标题，避免键盘焦点留在已移除的元素上。

所有价格、权益和更新记录均明确标注为示例。方案入口只打开说明，
不创建订单、不收集支付信息、不连接交易。真实订阅、账号服务、CMS 和 SEO 服务端渲染不在本轮范围。

## 实现边界

页面在 `src/pages/PublicPatternsPage.vue`，复用已有 Input、Icon、Tag、Collapse。
没有新增公共组件，没有更改各端适配或覆盖矩阵。
内容、搜索、价格口径和地址规范化只在 `packages/common/src/logic/public-pattern.ts`。
数据使用整数分，年付参考月均四舍五入到分；不从网页文案反推金额。
搜索按字面匹配，不执行正则或 HTML；未知栏目和失效文章不会静默打开其他内容。
